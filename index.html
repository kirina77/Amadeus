1先准备两样东西

一部能装 App 的手机，和一把大模型钥匙。语音钥匙可选。

① 一部安卓手机

安卓 8.0 以上，必须是 arm64（2020 年后的机器基本都是）。

包 897MB，装完占约 0.9GB；第一次让她动手机还会再解约 1.1GB 的运行时——留 3GB 空闲比较稳。

② 两把钥匙

大模型钥匙（必须）：决定她用哪个脑子。去 DeepSeek 官网 platform.deepseek.com 注册，在「API Keys」建一个，复制出来的 sk-… 一整串。

语音钥匙（想要声音才要）：Fish Audio（fish.audio）注册后建一把；或阿里云百炼的 CosyVoice 钥匙。

别把钥匙发群里。 它等同手机号加密码，别人拿到能用你的额度。费用是你自己账号的事，几块钱能用很久。

2把包装上

安装包在群里（QQ 1130679223），拿到后三步。

  1. 把 .apk 传到手机上（QQ 传或网盘下）。
  2. 点开安装。第一次会提示「未知来源应用」，按提示允许一次。
  3. 如果提示 「签名不一致」：手机里还装着别的来源的旧版，先卸载旧的再装——卸载会清空旧聊天记录。
装完先别急着开。 第一次启动要解模型，最好插着电、连着 Wi-Fi，别切后台。

3第一次打开：只做三步

打开后停在「连接电脑」页——不用连电脑，看下面那颗按钮。

1

装人格

点「装人格，独立使用」。人格装进手机里，默认日语，想换中文在设置 →「本机人格」里改。

2

填大模型钥匙

会自动跳到这一页。三项一起填，然后保存：

  • 服务地址：填到 /v1 为止
  • 模型名：照所选服务的文档写
  • 钥匙：粘贴那一整串 sk-…

地址照抄下面这一行即可（DeepSeek）：

https://api.deepseek.com/v1

模型名填 deepseek-chat。任何「OpenAI 兼容」的服务都能用（智谱 / Moonshot / 通义 / OpenAI），Anthropic、Gemini 的原生接口接不上。

3

填语音钥匙（可选）

想让她出声就填，不填也能用，只是没声音。二选一，填完保存：

Fish：地址、模型照抄

wss://api.fish.audio/v1/tts/live
s2.1-pro-free

千问：模型 cosyvoice-v3.5-flash，钥匙填你的，音色填 voice_id 编号。

顶部写着 「待配对」是正常的，那只表示没连电脑，不影响使用。

4主页怎么用

三样东西：输入框、麦克风、加号。

打字

底部输入框，回车发送。

说话

按住左下角麦克风。语音在本机识别，录音不上传。她说话时你直接开口就能插话。

加号（右下角）

相册、屏幕共享、情绪、悬浮桌宠；第二页是「这台手机」——陀螺仪视角、主动搭话挡位。

右上角

设置。换人格、换钥匙、改字大小、更新版本都在里面。

第一次说话会弹麦克风权限，点「允许」；摄像头同理。

5想让她帮你操作手机

可选，但很好用：点屏幕、打字、开应用、截屏、锁屏。

先开一个系统开关：

设置 → 无障碍 → 已下载的应用 → Amadeus → 打开

MIUI / 澎湃可能在「设置 → 无障碍 → 已下载的应用」里；有的系统在这一页还要再点一次「允许」。

开好之后，直接说「帮我打开设置把亮度调低」这种话，她会自己动手，做完回你一句。

  • 没开也能正常聊天，只是她会说「无障碍服务没开，这轮我点不了屏幕」。
  • 一轮最多 25 个动作、3 分钟，到点自己收场。
  • 中途想停，说「停下」。

6连电脑（可选）

不连也完全能用，先跑几天再连也行。

电脑上启动 Amadeus 桌面端，它会显示一个地址和一个配对码。手机进「连接电脑」页，填进去、连上。

之后她能看电脑屏幕、读写电脑文件、两边共用同一份记忆。

7常见问题

点开看答案。

启动动画出现后，闪退回桌面

多半是第一次启动解模型时被打断，或内存不够。清掉后台再开一次；还是不行就「设置 → 应用 → Amadeus → 存储 → 清除数据」重来。反复这样，把「设置 → 崩溃与脚本错误」里的内容复制给作者。

「钥匙被拒了（401）」

钥匙无效或没复制全。重新复制整串，注意别带多余空格；填完点保存。

她没有声音 / 「还差一把声音的钥匙」

语音钥匙没填。去设置 →「语音的钥匙（Fish / 千问）」填好保存，状态行会显示「已保存」或具体原因。

麦克风、摄像头点不开

手机设置 → 应用 → Amadeus → 权限，把麦克风、相机打开。

手机发烫、动画卡

设置 →「画面档位」→ 省电。省电档会自动关掉陀螺仪视角。

她老是不理我

看设置里的「勿扰模式」和「睡眠时段」——开着的话她不会主动开口。

想更新版本，一定要数据线吗

不用。设置 →「更新我自己」，按提示换掉 App。

包为什么这么大

本机语音识别、本机情绪模型、检索模型、立绘，还有让她动手机的整套运行时都在包里，不是缓存。第一次动手机时才会解开那 1.1GB。

8关于这个包

含人格（日中英，默认日语）、本机语音识别、本机情绪模型、检索模型、立绘表情，以及干活用的运行时。

不含任何人的聊天记录、头像、私人地址与密钥。钥匙只存在你手机里；卸载＝清空这台手机上的记忆。
